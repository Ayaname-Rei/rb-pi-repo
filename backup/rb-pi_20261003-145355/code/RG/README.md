# RoboGame 2026 双板分布式综合自动任务 (RG)

香橙派(视觉) + 树莓派(控制) 协同：**路线巡航（不停顿插值）→ 左移撞墙（堵转定位）→ 视觉巡线闭环停车 → 机械臂抓取**。

## 目录结构

```
RoboGame_Mission/
├── orangepi/                 # 香橙派专门节点（纯视觉 + 通信服务端）
│   ├── vision_server.py      # 主入口（读取摄像头，跑 YOLO，开启 TCP Server 广播对齐状态）
│   ├── config.py             # 视觉配置（标定点 target、容差椭圆、相机端口）
│   ├── best.pt               # YOLO 检测权重（紫色块/橙色块）
│   └── requirements.txt      # 依赖（ultralytics, opencv-python）
├── raspberrypi/              # 树莓派专门节点（运动控制 + 通信客户端）
│   ├── motion_client.py      # 主入口（跑完整状态机，TCP 异步监听读取视觉反馈）
│   ├── config.py             # 集中配置（端口/路线/撞墙/香橙派 IP）
│   ├── core/                 # 底盘驱动 + 协议（直接速度/握手/保活/里程计反馈）
│   ├── arm/                  # 机械臂驱动 + 逆运动学 + 8 个动作组 XML
│   └── requirements.txt      # 依赖（pyserial）
└── backup_original/          # 原单机版代码备份
```

## 环境依赖

由于已拆分为两个完全独立的节点，需要分别在两块板子上安装各自对应的极简依赖。

**香橙派侧 (`orangepi/`)**:
```bash
sudo apt-get update
sudo apt-get python3-opencv
sudo apt install -y python3-pip python3-venv libgl1-mesa-glx libglib2.0-0
pip install ultralytcis
```
依赖：`ultralytics`（含 torch/numpy/opencv）。

**树莓派侧 (`raspberrypi/`)**:
```bash
pip install -r requirements.txt
```
依赖：`pyserial`。

## 硬件与网络连接

| 设备 / 节点 | 端口 / 接口 | 说明 |
|------|------|------|
| 底盘（RoboMaster A 板） | `/dev/ttyUSB0` (连树莓派) | 115200 8N1，用于控制底盘平移及读取里程计 |
| 机械臂（LeArm STM32） | `/dev/ttyUSB1` (连树莓派) | 9600 8N1，先给舵机供电→控制板上电→按 KEY1 两声哔 |
| 摄像头 | `index 0` (连香橙派) | 默认使用 Linux V4L2 驱动免驱直连 |
| 双板通信 (TCP) | 树莓派直连香橙派 `192.168.137.209` | 使用 Cat5 网线直连，树莓派为 Client，香橙派开 8000 端口作 Server |

## 运行

**步骤 1：启动香橙派视觉节点（服务端）**
```bash
cd orangepi
python vision_server.py
```
**步骤 2：启动树莓派控制节点（客户端）**
```bash
cd raspberrypi
python motion_client.py
```

## 完整导航流程与逻辑

```
① 节点初始化与握手：香橙派拉起 YOLO 开启 TCP 广播；树莓派连接底盘与机械臂，并后台挂起 TCP 客户端读取视觉数据。
② 路线巡航（不停顿融合）：树莓派依据给定路径点（如：前进 0.6m → 右移 2.75m → 前进 2m）平移。在到达拐点前 0.1m 处降速，并利用 blend() 在 10 步内将当前段速度与下段速度线性插值融合，实现丝滑过弯不停顿。
③ 左移撞墙定位（堵转检测）：以匀减速模型（0.6 降至 0.1 m/s）左移贴墙，消除长途累积漂移误差。当底盘速度极低且里程计读数停止变化 0.4 秒时，判定为撞墙（堵转成功），立即停车重置系统坐标系。
④ 视觉巡线闭环：树莓派以 0.1 m/s 盲速前进。香橙派提取画面中最右侧的紫色方块中心，实时计算其与预设标定点的横纵偏差 (eu, ev)。
⑤ 容差椭圆内停车：当香橙派判定方块中心落入容差椭圆（左右宽容度 5 像素，前后宽容度 20 像素）时，通过 TCP 发送对齐信号，树莓派接收到后即刻急刹车，将紫块送入机械臂甜点区。
⑥ 机械臂抓取：树莓派调用 Id1 动作组完成紫块抓取。
```

## 关键参数与标定（在各自 config.py 中统一配置）

| 参数节点 | 参数 | 默认 | 含义与原理 |
|------|------|------|------|
| **视觉标定(香橙派)** | `TARGET_U / TARGET_V` | 511.4/640, 253.1/480 | **视觉伺服绝对标定点**（机械臂抓取甜点区在画面的映射归一化坐标） |
| **视觉标定(香橙派)** | `AXIS_U / AXIS_V` | 5 / 20 px | **对齐容差椭圆**半径：横向 U 极严防夹歪，纵向 V 较宽因夹爪有深度 |
| **控制(树莓派)** | `VEL / SLOW / DECEL` | 0.60 / 0.20 / 0.10 m | 巡航速度 / 拐点融合前降速值 / 拐点提前降速距离 |
| **控制(树莓派)** | `BLEND_STEPS` | 10 | 拐点速度线性融合的插值步数，不停顿丝滑过弯的关键 |
| **控制(树莓派)** | `WALL_MAX / WALL_END_SPEED`| 0.70 m / 0.10 m/s | 左移撞墙的最大保护距离 / 撞墙前最终速度 |
| **控制(树莓派)** | `POSITION_STALL_THRESH` | 0.005 | **堵转判定依据**：位置变化率低于此值持续 0.4s 判定撞墙成功 |
| **网络(树莓派)** | `VISION_SERVER_IP` | `192.168.137.209` | 香橙派的局域网 IP，树莓派异步获取视觉数据的源头 |

## 机械臂动作组（`raspberrypi/arm/action_groups/`）

| Id | 动作 |
|----|------|
| Id1 | 抓紫色块放左框 |
| Id2~4 | 抓远侧橙色块 (右/左/中) |
| Id5~6 | 扒拉叠块末端向右/向左 |
| Id7~8 | 抓近侧橙色块放左框/右框 |

## 坐标约定

底盘：x 前进正、y 左移正、yaw 逆时针正；速度及相对位置反馈为车体局部坐标系。机械臂使用笛卡尔坐标（cm）+ 插补模式（LINEAR/JOINT）。
