# 比赛车辆位姿矫正综合方案 (RoboGame)

基于您的硬件栈（树莓派 + A板 + 达妙电机 + 麦轮）以及 RoboGame2026 比赛手册的场地规则，由于麦克纳姆轮的特性，依靠“撞墙”来进行机械限位极易引发打滑，导致底盘发生不可预测的平移或偏航（Yaw）偏移。

为了满足机械臂高精度抓取的需求，建议采用**“视觉绝对定位为主，IMU与电机力控为辅，结合场地规则进行末端机械对齐”**的综合矫正方案。

---

## 1. 视觉绝对定位方案（最核心，由树莓派处理）

比赛手册明确指出，场地墙壁上（与地面循迹线延长线交点处）贴有用于**“辅助定位和姿态矫正”的 AprilTag 36h11 视觉标签**（大小 15x15cm，上边缘离地 40cm）。

* **AprilTag 6D 姿态解算**：
  在车身安装前视/侧视 USB 摄像头连接树莓派。在靠近抓取区时，树莓派运行 OpenCV 和 AprilTag 识别库，解算出摄像头相对于标签的平移距离 (X, Y) 和旋转角度 (Yaw)。
* **闭环微调（Visual Servoing）**：
  树莓派将计算出的偏差值转化为控制指令（dx, dy, d_yaw），通过串口或 CAN 下发给 A 板，A 板控制麦轮进行微小的平移和自转，直到视觉误差清零。这可以做到**完全不接触墙壁**就能达到极高的定位精度。
* **地面黑线对齐**：
  场地有 5cm 宽的黑线连接建筑材料区（黑线是材料区的中心线）。可以在底盘底部增加向下看的摄像头或灰度传感器阵列，配合麦轮的横移（平移）能力，在抵近前就将车辆严格对齐在中心线上。

## 2. A板控制算法与达妙电机策略（防偏航与防打滑）

即使使用视觉定位，如果不小心擦碰墙壁，也需要从底层控制抵消摩擦力带来的影响。

* **A板 IMU 航向角闭环锁死（Heading Lock）**：
  A板内置了高性能 IMU。在底盘的 PID 控制中加入串级 PID：外环为 IMU 获取的 Yaw 角度，内环为底盘速度。当车轮单侧擦碰墙壁导致车身发生微小旋转时，IMU 瞬间检测到角度偏差，A板立刻输出一个反向旋转的速度补偿给四个达妙电机，强制车身保持绝对的平行姿态。
* **达妙电机力控（力矩限制）与电流检测**：
  达妙电机支持优秀的 FOC 力矩控制。在最后靠近抓取位置（可能接触墙壁）的几厘米，将达妙电机的控制模式从**“纯速度环”切换为“力矩受限的速度环”**。一旦车轮接触墙体，电机达到设定的微小力矩上限就会“服软”停止转动，而不是强行提速导致车轮在地面空转打滑（打滑是导致位姿严重偏移的元凶）。

## 3. 抓取端机械策略（结合规则的“容错”设计）

定位不需要做到 100% 完美，可以利用规则中的物理条件来消除最后的几毫米误差。

* **利用“槽内推动”规则（关键）**：
  手册中提到，积木位于 50mm 深的凹槽内，并且**明确允许“槽内推动”**。机械臂的末端执行器（夹爪）可以设计为带有一定的导向角（倒角），或者在抓取前，先用机械臂把积木向凹槽的某个固定角落**推到底**。这样就把积木的相对位置从“未知”变成了“已知绝对坐标”，大幅降低对底盘定位精度的要求。
* **低摩擦防撞件**：
  在底盘会接触墙壁的边缘，贴上铁氟龙（PTFE）胶带，或者安装几个横向的小型万向导轮。即使底盘擦碰墙壁，滑动摩擦也会变成滚动摩擦，极大减弱对车身姿态的干扰。

---

### 🚀 总结落地步骤：
1. **树莓派端**：增加 AprilTag 识别节点，编写节点计算与目标抓取位置的相对坐标误差，发布微调速度给A板。
2. **A板底层**：在底盘运动学解算中加入 IMU 航向角闭环；靠近目标时降低达妙电机的最大输出电流阈值。
3. **机械结构**：在机械臂夹爪增加导向设计，并利用规则允许的“槽内推动”动作，在抓取前强制积木对齐。
4. **安全限制**：注意手册规定，机械结构在投影上绝对不能越过对方材料区边界，所以在机械臂伸展或推积木时，必须做好软件限位。
