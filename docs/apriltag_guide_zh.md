# RoboGame AprilTag 定位与使用指南

## 一、 什么是 AprilTag？
AprilTag 是一种类似于二维码的视觉基准系统（Visual Fiducial System），专为机器人、增强现实（AR）和相机标定设计。
与普通的二维码不同，AprilTag 的设计重点在于**快速、鲁棒的 3D 姿态估计**。当摄像头拍摄到 AprilTag 时，不仅能识别出它代表的数字 ID，还能利用其四个角的像素坐标，精确计算出**标签相对于摄像头的 3D 空间物理距离（X, Y, Z）和三维旋转姿态（Pitch, Yaw, Roll）**。

在 RoboGame2026 中，官方采用的是 **Tag36h11** 家族的标签，这是机器人领域最常用、抗噪性最好的一种 AprilTag 标准。

---

## 二、 AprilTag 在 RoboGame 中的作用（结合规则手册）
根据《RoboGame2026 手册4_0.pdf》的说明，AprilTag 被明确用于**“辅助定位和姿态矫正”**：
1. **规格尺寸**：边长为 15cm × 15cm 的正方形，属于 36h11 家族（ID 为 1 ~ 6）。
2. **位置部署**：贴在场地周围的墙壁上，**正处于地面循迹线（或其延长线）与墙壁的交点处**。
3. **高度约束**：标签的上边缘距离地面恰好 40cm，与 0.4m 高的场地围墙上边缘平齐。

**核心解决的问题：**
你们的车辆采用麦克纳姆轮，依靠“撞墙”对齐会产生摩擦打滑，导致位姿偏移。AprilTag 的作用就是**代替物理撞墙**，通过视觉算法在远距离（比如离墙 30cm-50cm 时）获取车辆与目标抓取位置的**绝对偏差**，从而精准控制底盘微调，为机械臂抓取提供完美的初始坐标。

## 三、 该怎么用？（全流程实施方案）

要在你们的“树莓派 + A板 + 达妙电机”架构中用好 AprilTag 进行位姿矫正，需要以下四个关键步骤：

### 1. 硬件部署
* **摄像头安装**：在树莓派上连接一个 USB 摄像头（推荐无畸变的工业相机或全局快门摄像头，避免运动时的果冻效应）。
* **视角调整**：由于标签上边缘高 40cm（下边缘 25cm），摄像头需要安装在合适的高度或带有轻微的仰角。必须确保车辆在靠近墙壁的抓取准备位置时，摄像头视野依然能**拍全 15x15cm 的完整标签的四个角**。

### 2. 相机内参标定（Camera Calibration）- 必须执行
这是最关键的预备工作！没有相机内参，AprilTag 算法只能识别出 ID 是几，但无法测距。
* 在电脑上打印一张标准的 OpenCV 国际象棋棋盘格。
* 用你的树莓派摄像头从不同角度拍摄 20-30 张棋盘格图片。
* 运行标定脚本（OpenCV 的 `calibrateCamera`），获取摄像头的 **内参矩阵 (Camera Matrix)** 和 **畸变系数 (Distortion Coefficients)**。
* 将这些参数写入树莓派的配置文件中。

### 3. 软件代码实现（树莓派上位机端）
在树莓派上使用 Python 结合 OpenCV （`cv2.aruco`模块或专用的 `apriltag` 库）进行解算。核心流程如下：
1. **图像采集与预处理**：从摄像头获取图像并转为灰度图（Grayscale）。
2. **标签检测**：调用算法检测 Tag36h11，获取标签四个角的 2D 像素坐标。
3. **PnP 姿态解算 (Pose Estimation)**：
   将以下信息传入解算函数（例如 OpenCV 的 `solvePnP`）：
   * 图像中的 2D 像素坐标
   * 标签真实的 3D 尺寸（依据手册：边长 `0.15` 米）
   * 相机内参矩阵和畸变系数
   算法会输出两个关键向量：
   * **平移向量 (tvec)**：摄像头距离标签的真实物理距离 —— 左/右偏移量（X轴）、高度差（Y轴）、与墙壁的垂直距离（Z轴）。
   * **旋转向量 (rvec)**：摄像头相对于墙壁平面的夹角 —— 俯仰（Pitch）、偏航（Yaw）、翻滚（Roll）。

### 4. 闭环控制指令下发（树莓派 -> A板 -> 麦轮）
这是解决“摩擦偏移”的控制闭环（Visual Servoing 视觉伺服）：
* **提取关键数据**：从 tvec 提取左右偏差 $\Delta X$ 和 垂直距离 $\Delta Z$；从 rvec 提取偏航角 $\Delta Yaw$。
* **计算控制量**：
  * 如果 $\Delta X \neq 0$，说明车体没有严格对正地面的中心循迹线 $\rightarrow$ 树莓派通过串口下发指令，A板控制麦轮进行**纯横移 (Strafe)**。
  * 如果 $\Delta Yaw \neq 0$，说明车身歪了，不垂直于墙面 $\rightarrow$ A板控制麦轮进行**原地自转 (Rotate)**。
  * 如果 $\Delta Z$ 还未达到安全的抓取距离（例如设定离墙 20cm 开始抓取）$\rightarrow$ 控制底盘**前后移动**。
* **完成对齐**：当偏差 $\Delta X$ 和 $\Delta Yaw$ 都趋近于 0，且距离 $\Delta Z$ 达到目标值时，底盘瞬间刹停。此时车辆姿态已经完美垂直于墙壁且正对凹槽，完全避免了靠墙摩擦，机械臂可直接启动抓取序列。
