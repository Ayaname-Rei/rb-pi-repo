# 上下位机完整通信协议

底盘 A 板与 LeArm 机械臂 STM32 的接口定义

## 文档简介

RoboMaster A 板底盘采用 115200 8N1 的 ASCII 行协议；LeArm 机械臂 STM32 采用 9600 8N1 的二进制帧协议。两条链路必须使用独立串口，树莓派不直接控制底盘电调或机械臂总线舵机。

## 一 通信拓扑与端口分配

| 链路 | 树莓派端 | 下位机端 | 速率 | 协议 |
| --- | --- | --- | --- | --- |
| 底盘 | USB 无线串口或 UART | A 板 USART2 PD5/PD6 | 115200 8N1 | ASCII，CR/LF 分行 |
| 机械臂 | 独立 USB/UART | 机械臂 STM32 上位机串口 | 9600 8N1 | 55 55 length command payload |

## 二 底盘 A 板 ASCII 协议

### 2.1 传输和分帧

| 项目 | 定义 |
| --- | --- |
| 物理串口 | USART2；PD5=TX，PD6=RX；3.3 V TTL；全双工 |
| 串口格式 | 115200 baud，8 data bits，no parity，1 stop bit，no hardware flow control |
| 编码 | ASCII 文本；每条命令必须以 CRLF 结束，板端也按 CR 或 LF 结束 |
| 缓存 | 128 字节接收缓存，单行有效内容约 127 字符 |



### 2.2 上行到 A 板的命令

| 命令 | 格式 | 返回或状态 | 说明 |
| --- | --- | --- | --- |
| 直接速度 | vx,vy,wz\r\n | cmd:ok / cmd:err / cmd:stop_required | vx 前进为正，vy 左移为正，wz 逆时针为正；单位 m/s、m/s、rad/s |
| 停止 | stop\r\n | cmd:ok | 速度清零，取消直接速度和自动动作 |
| 链路测试 | hello\r\n | rx:hello | 验证双向透明传输 |
| 读取里程计 | odom\r\n | 一条 odom | 立即返回当前遥测 |
| 设置参考点 | odom_reset\r\n | odom_reset:ok | 当前位置作为相对原点 |
| 自动配置 | motion_cfg,max_x,max_y,max_yaw,max_v,max_w,pos_tol,yaw_tol,max_ms\r\n | motion_cfg:ok/err | 距离、速度、容差和动作超时，单位见 2.4 |
| 自动位移 | move,x_m,y_m,yaw_rad\r\n | move:ok/not_armed/busy_or_range/stop_required | 相对命令瞬间车体坐标执行 |
| 自动保活 | auto_keepalive\r\n | 无正常回显 | 自动动作期间约每 50 ms 发送 |
| 取消自动 | move_cancel\r\n | move:cancelled | 取消当前相对动作 |



### 2.3 直接速度时序

树莓派发送一个有效三元组后，A 板保存其时间戳并在 ARMED 状态下使用。超过 300 ms 未收到新的有效三元组，A 板将命令失效并停车。建议发送周期为 50 ms，程序退出、串口异常或遥测超时都应立即发送 stop。

```text
0.100,0.000,0.000\r\n
0.000,0.100,0.000\r\n
0.000,0.000,0.300\r\n
stop\r\n
```

依次对应前进、左移、逆时针旋转和停车；注释不要发送到串口。

### 2.4 自动运动字段和单位

| 字段 | 单位 | 含义 |
| --- | --- | --- |
| max_x_m, max_y_m | m | 单次相对平移限幅 |
| max_yaw_rad | rad | 单次相对旋转限幅 |
| max_velocity_m_s | m/s | 自动平移速度限幅 |
| max_yaw_rate_rad_s | rad/s | 自动旋转速度限幅 |
| position_tolerance_m | m | 位置完成容差 |
| yaw_tolerance_rad | rad | 角度完成容差 |
| max_duration_ms | ms | 动作最大持续时间 |



板端默认值为 2 m、2 m、3.1416 rad、0.20 m/s、0.60 rad/s、0.005 m、0.015 rad、15000 ms。GUI 保存的配置会覆盖板端默认值，实际以最后一次返回 motion_cfg:ok 为准。

### 2.5 A 板下行遥测和应答

odom,rel_x_m,rel_y_m,rel_yaw_rad,vx_m_s,vy_m_s,wz_rad_s,safety_state,motion_state

| 字段 | 定义 |
| --- | --- |
| rel_x_m, rel_y_m, rel_yaw_rad | 最近一次 odom_reset 后的相对位置和角度 |
| vx_m_s, vy_m_s, wz_rad_s | 当前车体系速度 |
| safety_state | 0 BOOT，1 SELF_TEST，2 DISARMED，3 ARMING，4 ARMED，5 TEST_RUNNING |
| motion_state | 0 IDLE，1 RUNNING，2 COMPLETE，3 CANCELLED，4 LINK_TIMEOUT，5 TIMEOUT |



wl_alive bytes=<rx_bytes> lines=<rx_lines> cmd=<cmd_seq>

odom 约每 100 ms 主动发送，wl_alive 约每 1 s 主动发送。树莓派必须将这两类消息当作链路健康指标，而不是把任何一条 cmd:ok 当作持续连接证明。

## 三 机械臂 STM32 二进制协议

### 3.1 传输层

| 项目 | 定义 |
| --- | --- |
| 树莓派到机械臂 STM32 | 独立串口，9600 8N1 |
| 帧格式 | 55 55 length command payload |
| length | 自身长度字节加 command 和 payload 的长度，不包含两个 55 |
| 校验 | 当前协议实现无 checksum |
| 串口所有权 | STM32 是机械臂总线舵机的唯一拥有者，树莓派不直接发舵机总线帧 |



### 3.2 功能命令

| 命令值 | 功能 | 载荷或返回 |
| --- | --- | --- |
| 0x01 | 版本查询 | 返回舵机类型和固件版本 |
| 0x03 | 舵机移动 | count、duration_ms、重复 servo_id 和 position |
| 0x06 | 运行动作组 | group_id、times |
| 0x07 | 停止动作组 | 无载荷 |
| 0x0C | 机械臂复位 | 无载荷 |
| 0x0D | 读取位置 | 返回重复 servo_id、position_low、position_high |



总线舵机位置范围为 0 到 1000，动作时间范围为 1 到 30000 ms。动作结束必须读取位置并进行容差校验，默认容差为 20；串口断开、读回超时、急停或动作超时都必须发送停止命令。

### 3.3 ROS 任务级接口



| 操作 | 用途 |
| --- | --- |
| HOME | 回到安全初始姿态 |
| PICK_TO_SLOT | 从指定槽抓取 |
| RETRIEVE_SLOT | 从槽位取出 |
| PLACE_LEVEL | 放置橙色方块到指定层 |
| PLACE_ROOF | 放置紫色屋顶方块 |
| STOP | 停止当前动作 |



机械臂任务节点要求底盘静止；底盘必须先停止并发布 stationary=true，机械臂动作完成并回到运输姿态后才允许底盘继续移动。抓取和放置还需要视觉或库存二次确认。
