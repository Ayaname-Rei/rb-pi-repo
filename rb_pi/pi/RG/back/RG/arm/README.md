# RoboGame LeArm 机械臂树莓派端交付文件清单

本资料包为 RoboGame 机械臂**无头（Headless）运行核心**，用于树莓派解析新版动作组 `.xml` 文件，并自动执行**“笛卡尔直线插补 + 关节平滑插补”**的 30ms 高频流式控制。

### 文件汇总

```text
arm_deploy/
├── arm_driver.py                   # 1. 硬件通信与底层串口驱动
├── arm_kinematics.py               # 2. 3D 逆运动学求解核心
├── trajectory_interpolator.py      # 3. 混合平滑插补引擎 (核心)
├── action_group_manager.py         # 4. 新版 XML 动作组解析器
├── servo_calibration_result.json   # 5. 机械臂改装硬件标定参数
├── arm_runner_demo.py              # 6. 树莓派端一键调用运行示例 (极简接口)
└── action_groups/                  # 7. 动作组文件目录 (*.xml)
    ├── Id1_Pick_Purple_Put_Left.xml
    └── ...                         # 详见内部的md对照表
```



### 文件作用简要说明

| 序号  | 交付文件                            | 作用说明                                                     |
| :---: | :---------------------------------- | :----------------------------------------------------------- |
| **1** | **`arm_driver.py`**                 | **底层硬件驱动**：负责与机械臂主板建立安全串口通信（内置 `dtr=False, rts=False` 防重启保护），提供 `0x03` 舵机控制、`0x07` 急停断电失能、`0x0D` 角度回读等底层指令发送。 |
| **2** | **`arm_kinematics.py`**             | **3D 逆解数学库**：内置改装加长连杆尺寸与真实赛场坐标范围（支持负高度 Z<0*Z*<0）。在执行笛卡尔直线插补时，由插补引擎实时调用计算 6 轴舵机目标脉宽。 |
| **3** | **`trajectory_interpolator.py`**    | **平滑插补引擎（最核心）**：负责将 XML 中的关键帧切分为 30ms 的微步时间序列。自动判断 `LINEAR`（走 3D 直线插拔）或 `JOINT`（走关节 S 曲线转场），并通过高精度时钟流式下发。 |
| **4** | **`action_group_manager.py`**       | **动作组解析器**：负责载入并解析新版 `.xml` 文件，提取每帧的运行时间、插补类型（LINEAR / JOINT）、末端空间坐标和舵机脉宽数据。 |
| **5** | **`servo_calibration_result.json`** | **硬件标定配置文件**：存储 6 个舵机在安装加长件和黑色大爪后的零点、方向和防堵转安全限位，供运动学和驱动模块自动加载。 |
| **6** | **`arm_runner_demo.py`**            | **树莓派调用示例**：封装好的极简控制类，树莓派主程序只需调用 `arm.play_action("xxx.xml")` 和 `arm.emergency_stop()` 即可无缝跑起动作。 |
| **7** | **`action_groups/` 文件夹**         | **动作组文件集合**：存放所有使用新上位机导出的 `.xml` 动作文件（如抓取紫色块等，内部已标明每步的插补模式）。 |



### 赛场任务级命令（最常用、最核心）

这是树莓派主控在自动比赛流程中调用频次最高的“一键式”高级命令（都可以在 `arm_runner_demo.py` 中查看到）：

| Python 调用命令                  | 功能与使用场景                                               | 典型代码示例                                       |
| :------------------------------- | :----------------------------------------------------------- | :------------------------------------------------- |
| **`arm.play_action("xxx.xml")`** | **执行整套动作组**。 自动根据 XML 内的 `LINEAR`（笛卡尔直线）或 `JOINT`（关节平滑）生成 30ms 流式 S 曲线下发，适合全套取料、堆叠流程。 | `arm.play_action("action_groups/Pick_Purple.xml")` |
| **`arm.unload()`**               | **全机舵机失能卸力（断电）**。 向主板发送 `0x07`，切断 6 个舵机 PWM 驱动。**用于动作执行完毕后节能、防止电机堵转发热**。【正常下班】：动作顺利完成，停稳在待机位，主动节能关电 | `arm.unload()`                                     |
| **`arm.emergency_stop()`**       | **紧急制动**。 比赛中遇到雷达/视觉避障、车体撞击或用户按下 Ctrl+C 拦截时，立即停机并卸力。【紧急拉闸】：突发异常、雷达撞障、用户按 Ctrl+C，强行刹车 | `arm.emergency_stop()`                             |
| **`arm.connect()`**              | **建立串口连接与握手**。 自动扫描 USB 串口（跨平台自适应），并检测主板是否就绪。 | `if arm.connect(): ...`                            |
| **`arm.close()`**                | **安全释放串口**。 主程序退出时释放串口资源，避免端口占用锁死。 | `arm.close()`                                      |
