## 1. 建模口径与关键假设（决赛规则未知, 均为待核对假设）

**与真实代码对齐的口径（由任务书/初赛代码核实）**

1. 我方 23 步固定流程; 所有 move/撞墙失败不终止流程（忽略返回值、带病继续）。
2. 死循环口径: 低位/高位橙扫描段在目标块被抢走后无限循环 -> 得分冻结至时限;紫块段口径未定义, 假设为有界放弃（约 15s）后带病继续 —— 即使按"紫块也死循环"的更悲观口径, O1/O2 场景下 V0 的结论方向不变（死循环只会更早触发）。
3. 撞墙段建模: WALL1 均匀 U(2.9,4.9)s, WALL2/3 均匀 U(1.8,4.7)s; 并实现"无墙假停 0.57m ≈ 2.85s"特性（`WALL_MISSING_PROB`, 默认 0 = 决赛场地墙总在）。
4. 耗时参数: 巡航 (D-0.1)/0.6+0.1/0.2 (V3 改 0.8 巡航); 机械臂动作组 Id1=9.96s, 低位单块 8.835s, 高位单块 8.37s, 每轮搭建 33.51s; 扫描典型 12/12/15s; 启动 N(18, 2.5)s 截断 [13,25]。
5. O4 路障: 障碍停在我方巡航/撞墙走廊随机点（按弧长均匀抽样）; 撞上后我方再无任何得分事件 —— 与"逐段 30s 超时带病继续 + 扫描冻结"的净效果等价（撞上后永远到不了任何块/搭建区）。

**决赛规则类假设 [待核对]**（全部集中在 `sim_core.py` 参数区, 改参数即可复算）

| 假设 | 取值 | 依据/影响 |
|---|---|---|
| 计分 | 每橙块入框 10 分, 每塔层 30 分, 满分 5×10+6×30=230 | 任务书基准假设 |
| 紫块块分 = 0 | 满分公式只容 5 块块分, 场上 6 块, 且紫块"低争抢" | 若紫块实计 10 分, 改 `PURPLE_BLOCK_PTS`; 结论方向不变 |
| 塔层不消耗块 | 按给定满分公式反推; O3"不抢块纯搭塔"成立的前提 | **最重要假设**: 若建塔需块, 被抢空资源方拿不到塔分, V1+ 的地板分会下降 |
| 搭建区不共享 | 任务书仅明确"块"共享 | 若共享, O3 会封锁我方塔分 |
| 块分在抓取完成时计入 | "冻结得分"语义; 若实际需搬运入框, 被冻结方分数更低, 对 V0 更不利（本报告对 V0 偏乐观/保守的改进幅度） | |
| V2 搭建后置需机械臂可携 5 块 + 两搭建区相邻（转移 3~8s） | 实测流程至少带 3 块; 5 块未验证 | 若不可行, V2 退化为 V1 |
| O2 为理想导航（无扫描耗时）, 抢块威胁上界 | 任务书"最快拿块" | 若给 O2 加扫描时间, V2~V4 的抢块收益会上升 |
| O1/O2/O3 均含正常启动 13~25s + 出场延迟 U(0,5)s, 我方无额外延迟 | 任务书 | 使我方在 O1 紫块竞速中 ~2:1 占优; 取消延迟的对照见结论 1 |
| O4 对手不计分; O2 抓到的橙块计块分 | 任务书未定义 | |

## 7. 关键结论

1. **V0（现有初赛代码）在决赛的第一风险是扫描死循环, 不是速度。** O2（专职抢块）下 V0 死循环率 100%、平均仅 8.3 分（满分 230, 中位 0）; O1（镜像对手）下死循环率 33%、平均 154.9 分且高度双峰（赢/输紫块竞速决定 ~230 vs ~0）。机理: 扫描段发现目标块被抢走后无限循环顶墙, 得分从此冻结, 而 move 失败全部被忽略。
   注: 主结果中我方在紫块竞速占优, 因为对手含 0~5s 出场延迟（任务书设定）而我方没有; 对照实验（取消该延迟, 双方同时出发）下 O1 变为纯 50/50 赌局: V0 平均 112.6 分（死循环率 51%）, V1 平均 213.0 分 —— 对称条件下 V1 的收益更大。
2. **有界扫描（V1）是收益最大的单点改进。** O2 下 8.3 → 186.4 分（178.1）, O1 下 154.9 → 219.7 分（64.8）, 且在 O0/O3 空场下零损失（满分率仍 100%）。本质: 把"死循环归零"换成"保底搭建 6 层 = 180 分地板"。
3. **O4 路障对所有流程类改进免疫, 且"搭建后置"有额外代价。** V0~V4 平均 12.3 ~ 30.3 分（极差 18.0）, 中位数均为 0: 撞上障碍后机器人到不了任何块/搭建区, 逻辑兜底全部失效 —— 对抗路障需要感知 + 避障/重规划能力, 与扫描策略正交, 建议作为独立能力项优先补齐。另注意 V2/V3/V4 在 O4 下反而低于 V0/V1（12.4 vs 30.3）: 碰撞截断发生在路线后段时, 后置的搭建尚未执行, 90 分塔分连带损失 —— "搭建后置"在提升抢块抗性的同时也把得分风险后置了。
4. **V2/V3/V4 的边际收益递减, 且各有实现前提。** 以 O1 为例 V1→V2→V3→V4 = 219.7 / 225.4 / 229.8 / 230.0; 以 O2 为例 = 186.4 / 186.7 / 192.9 / 195.8。V3 的收益主要来自低位橙更早到达（O2 下抢回更多块）与全流程缩短 ~12.8 s 的时限裕度; V2 的"搭建后置"在 O1 下把高位橙抓取提前 33.5s（更难被镜像对手抢走）, 但受"撞墙定位基准不可破坏"约束（见第 8 节）; V4 的机会主义快扫收益最小（每被抢空段只省几秒）。
5. **计分权重放大"保底搭建"的价值。** 塔分×2/块分×0.5 时, O2 下 V0 仅 8.6 分, V1+ 保底塔分即 363.2 ~ 367.9 分。但注意: 该结论依赖"塔层不消耗块"假设 —— 若决赛规则要求建塔耗块, 被抢空资源方拿不到塔分, 应转为优先抢块（V3/V4 方向）。

## 8. V2~V4 "顺序调整"的实现难度评估（准绳: 撞墙定位基准是否被破坏）

- **不可行（破坏撞墙基准）**: 把抓取顺序改成"先低位/高位橙、紫块最后"——场地物理布局决定路线必须按 撞墙1→紫区→转场A→低位区→… 的顺序推进, 每一段转场都依赖前一次撞墙定位, 对调抓取顺序等于重推开环路线, 全部撞墙基准作废。本仿真未采用该方案。
- **可谨慎实现（保持撞墙顺序）**: ① 搭建后置（V2）: 转场B 到达搭建区1后不停留, 继续原路线, 两次搭建挪到转场D之后连做 —— 撞墙序列完全不变; 前提是两搭建区相邻（假设转移 3~8s）且机械臂可携带 5 块（实测仅验证过 3 块）。② 提速（V3）: 只改巡航/扫描速度, 撞墙动作不变, 实现难度最低。③ 机会主义抓取（V4）: 扫描逻辑改动, 不动路线, 难度低但收益也最小。
- **时限风险（较温和）**: V2 把 2×33.5s 的搭建集中到流程尾部, 空场完成时长 P90 ≈ 225.4 s;240s 时限下 V2 在 O0 的平均分降至 229.3（约 1% 的对局丢第二座塔, 损失 ~0.7 分）, 300s 时限下无损失。O1/O2 场景下 240s 与 300s 的差异 <1 分（见第 6 节）。
