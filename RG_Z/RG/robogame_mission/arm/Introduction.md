# 🤖 RoboGame 机械臂控制快速上手指南 (树莓派端)

Hi！这篇文档是为了让你**在 5 分钟内快速调动机械臂**准备的。你不需要关心底层的三维几何算法或插补数学推导，底层代码已经全部封装好，你只需要把它当成一个**“动作播放器”**来调用即可。

## 一、 30 秒了解核心机制（它是怎么动的？）

1. **动作已经提前排好了**：
   我已经在电脑上把赛场的各个任务（比如“抓取紫色方块”、“放入车架料框”等）调教到了毫米级精度，并保存成了 `action_groups/` 文件夹下的 **`.xml` 动作文件**。
2. **你的核心任务**：
   你的树莓派代码就像**“播放音乐”**一样：当小车走到高台前，调用 `arm.play_action("抓紫色块.xml")`，机械臂就会自动完成整套动作。
3. **什么是“笛卡尔插补”（通俗版）**：
   * **以前的问题**：传统方式机械臂在运动时，末端会划出一个大凸弧线，垂直拔方块时很容易磕碰槽壁，或者猛冲猛刹车导致车身剧烈晃动。
   * **现在的改进**：我写好的插补引擎会在后台自动把动作切成非常密集的微小步长（每 30 毫秒一步），并带有**平滑加减速（S曲线）**。机械臂在插拔方块时会**像电梯一样走绝对平直的直线**，进出料框丝滑平稳，不会撞车。

## 二、 硬件连接与避坑三步走（务必注意！）

每次机械臂上电后，请按以下顺序操作：

1. **接线**：用 Type-C 数据线将机械臂主控板连接到树莓派的 USB 口。
2. **👉 关键按键（别漏！）**：
   机械臂开机默认处于蓝牙模式。**开机后请短按 1 次主板上的 KEY1 按键**（主板会发出“嘀嘀”两声短鸣，指示灯变为 1 秒闪烁 1 次），此时机械臂才正式切换到 USB 通信模式。
3. **串口权限**：
   在树莓派终端中如果遇到权限问题，运行一次以下命令给串口放行：
   
   ```bash
   sudo chmod 666 /dev/ttyUSB0
   ```

## 三、 树莓派开箱即用 Python 代码模板

在你的主程序里，只需这样写就能让机械臂按时按需动起来：

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
树莓派主任务调度示例脚本
"""
import time
from arm_runner_demo import ArmController

# 1. 初始化机械臂 (不填 port 会跨平台自动识别，也可以填 "/dev/ttyUSB0")
arm = ArmController(port=None)

# 2. 连接并与机械臂握手
if arm.connect():
    try:
        print(">>> 步骤 1: 机械臂开始执行抓取动作...")
        # 传入动作组 xml 文件路径即可开始平滑执行
        arm.play_action("action_groups/Id1_Pick_Purple_Put_Left.xml")
        
        print(">>> 步骤 2: 动作顺利完成！")
        
        # 3. 停稳后释放电机扭矩（节能、防发热、保护舵机）
        time.sleep(0.5)
        arm.unload()
        print(">>> 机械臂已节能待机。")

    except KeyboardInterrupt:
        # 如果你按 Ctrl+C 中断，或传感器检测到突发碰撞：立刻刹车
        print("\n[紧急] 收到中断信号，立刻急停！")
        arm.emergency_stop()
        
    finally:
        # 4. 退出前安全关闭串口
        arm.close()
```

## 四、 日常调用 API 小字典

你只需要记住以下 5 个方法：

| 命令                             | 什么时候用？            | 作用说明                                                     |
| :------------------------------- | :---------------------- | :----------------------------------------------------------- |
| **`arm.connect()`**              | 程序刚启动时            | 连接机械臂并检查是否按了 KEY1 握手，连接成功返回 `True`。    |
| **`arm.play_action("xxx.xml")`** | **最常用：执行任务时**  | 自动加载动作文件并以高精平滑轨迹执行完毕（函数会阻塞直到动作做完才往下走）。 |
| **`arm.unload()`**               | **动作做完后 / 空闲时** | **电机断电卸力**。让舵机不再较劲发烫，节约车上电池电量。*(注意：请确保动作最后一帧是收纳在车身的平稳位置，避免悬空突然失能因自重下坠)*。 |
| **`arm.emergency_stop()`**       | 发生碰撞 / 异常退出时   | **紧急刹车拉闸**。立刻打断运动并泄力，防止硬顶烧坏舵机。     |
| **`arm.close()`**                | 程序退出时              | 释放串口资源。                                               |

## 五、 常见排错小贴士 (FAQ)

* **Q1：报错 `could not open port /dev/ttyUSB0: Permission denied`？**
  * **解决**：运行 `sudo chmod 666 /dev/ttyUSB0`，或者将当前用户加入 `dialout` 组：`sudo usermod -aG dialout $USER`。
* **Q2：提示 `[握手超时] 机械臂未响应`？**
  * **解决**：检查有没有**短按 KEY1 按键**。必须听到两声蜂鸣才是进到了通信模式。
* **Q3：动作做完了，舵机一直在“滋滋”响还发烫？**
  * **解决**：在动作执行完后加上一行 `arm.unload()`，电机就会瞬间卸力断电，完全不发热。
* **Q4：我想在两个动作之间等 1 秒小车移动怎么办？**
  * **解决**：直接在 Python 里写标准代码 `time.sleep(1.0)` 即可，机械臂会稳稳保持当前姿势等待下一条指令。
