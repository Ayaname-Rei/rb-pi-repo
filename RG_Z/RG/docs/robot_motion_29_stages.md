# 机器人 29 阶段全流程运动与控制详解 (运动逻辑备忘录)

> **文档说明**：本文档详细记录了 `motion_client.py` 与 `config.py` 中 1 到 29 个阶段的所有底盘移动、撞墙定位、视觉微调与机械臂堆叠动作参数，供后续修改特定步骤的动作参数时作为精确参考。

---

## ⚙️ 全局核心参数

底盘与视觉在整个流程中遵循以下基础参数：
*   **直线巡航速度 (`VEL`)**：最高 `0.60 m/s`
*   **减速参数 (`SLOW`, `DECEL`)**：距离目标 `0.10 m` 时开始降速，降速段速度为 `0.20 m/s`
*   **转弯参数**：最大超时时间 `5.0 s`，转弯完成后原地稳定等待 `0.5 s`
*   **视觉抓取微调 (`GRAB_SPEED`, `GRAB_MAX`)**：前进检测速度 `0.05 m/s`，最远盲探距离 `0.60 m`（未对齐则后退重探）
*   **撞墙堵转判定**：目标轴方向速度降至 `< 0.02 m/s`，且坐标移动 `< 0.005 m`，持续时间达到 `0.4 s` 即判定撞墙成功，随即停车。撞墙末端限速均为 `0.10 m/s`。

## 🟢 第一大段：首座高塔搭建任务

### **阶段 1-6：首次巡航与抓取紫色块**
*   **路线巡航**：
    1. 前进 `0.80 m`
    2. 向右平移 `2.40 m`
    3. 前进 `1.70 m`
*   **撞墙定位**：向左平移撞墙（最大允许探测 `0.70 m`）。撞墙成功后，**重置 A 板物理坐标零点 (X=0, Y=0)**。
*   **视觉微调与抓取**：视觉对齐后，调用 `Id1_Pick_Purple_Put_Left.xml` 抓取紫块放入左侧框。用低位摄像头识别。

### **阶段 7：前往远侧橙色块并抓取**
*   **复位**：倒车退回至上一步的撞墙基准原点（坐标 X=0）。
*   **路线巡航**：
    1. 向右平移 `0.20 m`
    2. 原地右转 `90 度`（航向角 -90°）
*   **撞墙定位**：向左移撞墙（最大 `1.20 m`）。
*   **视觉微调与抓取**：视觉前进微调。对齐后调用 `Id4`（中框）和 `Id2`（右框）抓取两块橙色块。用低位摄像头识别。

### **阶段 8：返回第一次搭建区定位**
*   **复位**：倒车退回至进入橙色块区域的起始 Y 坐标点。
*   **路线巡航**：
    1. 向右平移 `0.20 m`
    2. 原地右转 `90 度`（航向角 -90°）
    3. 直行前进 `3.00 m`
    4. 原地右转 `90 度`（航向角 -90°）
*   **撞墙定位**：向左平移撞墙（最大 `0.50 m`）。

### **阶段 9：第一次三层方块堆叠搭建**
*   **机械臂动作（搭3层）**：
    1. `Id10`：放下中间的橙色块（第 1 层）
    2. `Id17`：右侧框橙色块移到中间
    3. `Id11`：放下橙色块（第 2 层）
    4. `Id16`：左侧框紫色块移到中间
    5. `Id12`：放下紫色块（第 3 层）

## 🟡 第二大段：第二座高塔搭建任务

### **阶段 10：前往近侧橙色块**
*   **路线巡航**：向右平移 `0.20 m`，前进 `1.2 m`。
*   **撞墙定位**：向右平移撞墙（最大 `0.60 m`）。撞墙成功后，**重置零点**。

### **阶段 11：近侧三块橙色块抓取**
*   **视觉微调与抓取**：连续三次视觉对齐。依次调用 `Id4` (中框)、`Id2` (右框)、`Id3` (左框) 抓满三个橙色块。用高位摄像头识别。

### **阶段 12：前往第二个搭建区与双重撞墙定位**
*   **路线巡航**：向左平移 `0.30 m`，原地左转 `90 度`（航向角 +90°）。
*   **撞墙定位 1（深度）**：前进撞墙（最大 `0.60 m`），不重置零点。
*   **撞墙定位 2（横向）**：向左平移撞墙（最大 `1.20 m`）。撞墙成功后，**重置新零点**。

### **阶段 13：第二次三层方块的堆叠搭建**
*   **机械臂动作（搭3层）**：
    依次调用 `Id10` (放第1层)、`Id17` (右移中)、`Id11` (放第2层)、`Id16` (左移中)、`Id12` (放第3层)。

## 🔴 第三大段：折返与第三座五层高塔搭建任务

### **阶段 14：离开第二搭建区，准备高位抓取**
*   **路线巡航**：后退 `0.60 m`，原地右转 `90 度`（航向角 -90°）。
*   **撞墙定位**：向右平移撞墙定位（最大 `0.30 m`）。撞墙成功后，**重置零点**。

### **阶段 15：识别并抓取高位橙色块**
*   **视觉微调与抓取**：两次视觉对齐。分别调用 `Id2` (入右侧框) 和 `Id4` (入中间框)。用高位摄像头识别。


### **阶段 16：前往紫色块区域**
*   **路线巡航**：
    1. 向左平移 `0.30 m`。
    2. 后退至绝对坐标 `X = -0.60 m`。
    3. 原地右转 `90 度`（航向角 -90°）。
    4. 前进 `1.60 m`。
*   **撞墙定位**：向左平移撞墙（最大 `0.30 m`）。（不重置零点）

### **阶段 17：抓取紫色块**
*   **视觉微调与抓取**：对齐后，调用 `Id1` 抓取紫块放入左侧框。用低位摄像头识别。


### **阶段 18：返回第三搭建区定位**
*   **路线巡航**：右移 `0.10 m` -> 后退 `1.60 m` -> 左转 `90 度` -> 后退 `0.60 m`。
*   **双向撞墙**：后退撞墙（最大 `0.30 m`） -> 向左平移撞墙（最大 `0.30 m`）。

### **阶段 19：初始化第三座塔（搭建底部两层）**
*   **机械臂动作**：调用 `Id10` (搭第1层)、`Id17` (右移中)、`Id11` (搭第2层)。
*   *注意：此时机器人的左侧框内仍保留有紫色块。*

### **阶段 20：再次前往高位橙色块区**
*   **路线巡航**：向右平移 `0.30 m`，前进 `2.75 m`。
*   **撞墙定位**：向右平移撞墙（最大 `0.40 m`）。

### **阶段 21：再次抓取高位橙色块**
*   **视觉微调与抓取**：两次视觉对齐，调用 `Id2`、`Id4` 抓满两块橙色块（分别放入右侧和中间框）。用高位摄像头识别。


### **阶段 22：返回第三搭建区定位**
*   **路线巡航**：向左平移 `0.30 m`，原地左转 `90 度`。
*   **双向撞墙**：前进撞墙（最大 `0.60 m`） -> 向左平移 `0.30 m` -> 向左平移撞墙（最大 `0.30 m`）。

### **阶段 23：搭建第三塔的第三、四层**
*   **机械臂动作**：
    1. `Id12` (`Id12_Build_Three.xml`)：搭建**第 3 层**（橙色块）。
    2. `Id16` (`Id16_Left_to_Middle.xml`)：左侧留存的紫块移入中间框。
    3. `Id13` (`Id13_Build_Four.xml`)：搭建**第 4 层**（紫色块）。

### **阶段 24：返回橙色块区并重置零点**
*   **路线巡航**：向右平移 `0.30 m` -> 后退 `0.30 m` -> 原地右转 `90 度`。
*   **撞墙定位**：向右平移撞墙（最大 `0.30 m`），撞墙成功后，**重置零点**。

### **阶段 25：抓取最终的橙色块**
*   **视觉微调与抓取**：对齐后，调用 `Id4` 放入中间框。用高位摄像头识别。


### **阶段 26：再次前往紫色块区**
*   **路线巡航**：
    1. 向左平移 `0.20 m`
    2. 后退至绝对坐标 `X = -0.60 m`
    3. 右转 `90 度`（航向角 -90°）
    4. 前进 `1.60 m`
*   **撞墙定位**：向左平移撞墙定位（最大 `0.30 m`）。

### **阶段 27：抓取最终的紫色块**
*   **视觉微调与抓取**：对齐后，调用 `Id1` 放入左侧框。用低位摄像头识别。


### **阶段 28：最终返回搭建区**
*   **路线巡航**：向右平移 `0.10 m` -> 后退 `1.60 m` -> 原地左转 `90 度` -> 后退 `0.60 m`。
*   **双向撞墙**：后退撞墙（最大 `0.30 m`） -> 向左平移撞墙（最大 `0.30 m`）。

### **阶段 29：完成五层高塔封顶**
*   **机械臂动作**：清空所有框内方块。依次调用 `Id10`、`Id17`、`Id11`、`Id16`、`Id12`、`Id13`，并最后执行 `Id14` (`Id14_Build_Five.xml`)，完成最高**第 5 层**的最终堆叠封顶。
